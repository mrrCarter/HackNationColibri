## Contribution format

Evidence packet: E-ID / question / original source + date or measured revision / verified fact / limitation / implication / artifact path / decision owner. Distinguish VERIFIED, MEASURED, PROPOSED and UNKNOWN. Perplexity and web are discovery tools; primary sources and experiments carry the proof. ChatGPT/Claude critiques are hypotheses until checked.

Handoff: lane + commit / changed paths / behavior / actual validation / unresolved risk / exact next owner. Blocker: input or failing step / expected vs observed / reproducible artifact / decision required. Put detailed tables/logs in files. Never include API keys, tokens, raw customer PII or unredacted audio in room messages.

## Delegation limits

Each primary builder owns at most one additional bounded diagnostic/research helper at a time, only if useful and resources permit. Helpers get a task, output path, allowed access and stop condition; they do not edit another lane, merge main, contact users or publish material automatically. Teammate helpers report through their human owner's reviewed packet. Use one Android build and one physical-phone benchmark at a time.
